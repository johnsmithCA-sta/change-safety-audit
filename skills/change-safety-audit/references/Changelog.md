# Changelog — change-safety-audit

## [1.2.1] - 2026-09-13

备份口径收窄：从「无差别要求备份」改为「默认不留备份」。

### Changed

- **铁律三重写**：「备份用固定名同名覆盖」→「**默认不留备份**」。新判据是**这次操作可逆吗**——可逆（改动可精确反向 / 上游 git 含 reflog / 系统废纸篓兜底）就不留任何副本；仅当退路全无（覆盖远端历史、强推、被平台重建的受管文件）才留底，且只留一处、固定名同名覆盖。原「固定名同名覆盖 / 带日期即熵增」保留为**要留时的命名规则**。
- `references/硬规则详解.md` 铁律三同步重写，为判据加「可逆 / 不可逆」对照表；**删除「删减前先 `tar` 打包归档」**——打包产物本身即又一份冗余副本、且解包才能用、极易被遗忘在磁盘，「可回退」由可逆改动 + 上游 git 承担。
- 终检序列第 10 步「与备份逐文件 diff」→「**逐文件核对基线 diff**」（无备份时与改动前 MD5 / 行数基线比对，不为这一步专门造备份）。SKILL.md 与 `references/并行编排与终检.md` 同步。
- summary / description / README 铁律条目同步为「默认不留备份」；触发词新增「要不要备份 / 默认不留备份」（**保留**原「备份策略 / 备份文件名 / 备份防熵增」以维持触发面）。
- `evals/case-03` 判分证据引文对齐新铁律三原文；断言本身不变（新铁律三仍含「带日期 = 必然熵增」，原断言继续成立）。
- 固化本轮踩坑：`references/硬规则详解.md` 新增次级规则「一处文件改多处：替换必须累积，断言挡不住覆盖」（实测脚本一次改 7 处、断言全过，实际只落 1 处）；SKILL.md 并行编排第 3 条同步扩写。
- version 1.2.0 → 1.2.1。

## [1.2.0] - 2026-09-12

并行编排能力补位。

### Added

- 新增 `references/并行编排与终检.md`：把一批改动分给多个 agent / 多个会话并行做时的**四条分工纪律**（按文件切分、共享口径逐字下发、并行竞态按常态处理、要求对方报「没做到的」）、何时值得并行的判据、**10 步终检序列**，以及四条实测踩坑。
- SKILL.md 新增「多 agent 并行改动的编排（执行方）」一节，与既有「多 agent 互评要不要」并列——**前者管怎么并行执行，后者管要不要拉第二意见核对**，两侧均写明分工。
- 触发词新增：多 agent 分工 / 多 agent 编排 / 并行整改 / 并行编辑 / 并行改一批文件。

### Changed

- description 282 → 374 字符：补并行编排适用场景与新触发词；排除项「新建文件」收窄为「单个新建文件」——并行批量新建同样需要编排，不应落在排除项里。
- README 同步：新增「多 agent 并行改动的编排」小节、目录结构补新文件，并去掉主入口的行数标注（易漂）。
- version 1.1.0 → 1.2.0。

### 备注

- 上一版登记的 `password_format` 4 项误报**已不复现**：工具侧的技能名自动豁免（frontmatter name / slug / 目录名）已覆盖 kebab-case 技能名，`preflight --strict` 现为零告警通过——本技能不再需要 `--waive password_format`。
